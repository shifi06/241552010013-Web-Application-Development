❓ FAQ

Dashboard ini adalah contoh implementasi komponen UI interaktif menggunakan HTML, CSS, dan JavaScript murni tanpa framework.

Klik tombol "Mode Gelap" di pojok kanan atas. Preferensi akan tersimpan otomatis dan tetap aktif saat halaman di-refresh.

Pada versi demo ini, data tidak tersimpan ke server. Hanya preferensi tema yang disimpan via localStorage.
