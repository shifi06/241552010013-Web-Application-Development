Contoh Box

Penjelasan properti yang digunakan:

  • width: 50%; - Lebar 50% dari parent (body)
  • height: 100px; - Tinggi 100 piksel
  • background-color: rgba(255, 0, 0, 0.5); - Merah dengan transparansi 50%
  • color: #333; - Warna teks abu-abu gelap (hex)
  • font-size: 1.5rem; - Ukuran font 1.5x dari ukuran root (biasanya 24px)
  • padding: 1em; - Padding 1x ukuran font elemen
