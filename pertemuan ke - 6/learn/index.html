Panduan Flexbox untuk Pemula Banget

17 April 2026 · 5 menit baca

Flexbox itu singkatan dari Flexible Box Module. Analogi gampangnya: bayangin rak toko. Kamu punya rak (container) dan barang-barang (item).

Properti Flexbox yang Wajib Tahu

display: flex → mengaktifkan flexbox di parent.
justify-content → ngatur posisi horizontal (kiri, kanan, tengah, nyebar).
align-items → ngatur posisi vertikal (atas, bawah, tengah).
gap → kasih jarak antar item, lebih bersih dari margin.
flex: 1 → item mengambil sisa ruang kosong.

Contoh navbar: justify-content: space-between bikin logo di kiri, menu di kanan.

⭐ Intisari Flexbox

Container (parent):
• display: flex
• justify-content (main axis)
• align-items (cross axis)
• gap (jarak antar item)

Item (child):
• flex: 1 (tumbuh ambil ruang)
• order (ubah urutan visual)
• align-self (override align-items)
